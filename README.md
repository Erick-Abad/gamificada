# La aventura de las vocales mágicas

Ambiente gamificado de aprendizaje para Lengua y Literatura, dirigido a niños de 4 a 6 años y estructurado con el modelo pedagógico 5E.

## Incluye
- Portada con datos curriculares y presentación del equipo docente.
- Enganchar: juego de identificación de vocales iniciales.
- Explorar: clasificación interactiva de palabras.
- Explicar: espacio para video propio de 3–5 minutos y tres recursos complementarios.
- Elaborar: creador de mural digital.
- Evaluar: cuestionario de 10 preguntas con retroalimentación automática.
- Sistema de puntos, progreso, sonidos, diseño responsive y accesibilidad básica.

## Ejecutar localmente
1. Instale Node.js.
2. Abra una terminal en esta carpeta.
3. Ejecute `npm install`.
4. Ejecute `npm start`.
5. Abra `http://localhost:3000`.

También puede publicar únicamente la carpeta `public` en Netlify, Vercel o GitHub Pages.

## Cambios obligatorios antes de entregar
- Sustituir los nombres de los integrantes.
- Insertar el video de autoría propia de 3 a 5 minutos.
- Revisar datos curriculares finales.
- Publicar el sitio y verificar el enlace público.
- Elaborar el PDF de entrega con portada, enlace, anexos e informe del líder.
